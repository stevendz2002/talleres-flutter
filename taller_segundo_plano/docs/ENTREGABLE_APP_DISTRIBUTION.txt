======================================================
CÓMO REPLICAR EL PROCESO
======================================================
1. Clonar el repo:
   git clone https://github.com/stevendz2002/talleres-flutter.git
   cd talleres-flutter/taller_segundo_plano

2. Instalar dependencias:
   flutter pub get

3. Generar APK de release:
   flutter build apk --release
   # APK en: build/app/outputs/flutter-apk/app-release.apk

4. Subir en Firebase Console:
   - Ir a App Distribution → Releases → Upload
   - Seleccionar app-release.apk
   - Agregar release notes
   - Asignar grupo QA_Clase
   - Distribuir

5. Para actualización:
   - Cambiar version en pubspec.yaml (ej: 1.0.1+2 → 1.0.2+3)
   - Repetir desde el paso 3

Documentación completa: docs/firebase/FIREBASE_SETUP.md
